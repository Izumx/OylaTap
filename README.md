# OylaTap

Образовательная платформа для школьников 11+ в Казахстане, учителей и авторов. Короткие вертикальные видео → микровопросы → итоговый тест → пересказ → прогресс. Первые направления — литература и история; также доступны алгебра и геометрия. Это не сервис подготовки к ЕНТ.

React + TypeScript + Vite, Express, **PostgreSQL 17** в Docker. Интерфейс на русском и казахском. Рабочая ветка — **main**, изменения отправляются напрямую коммитами.

## Текущее состояние — 17 октября 2026

- **Лента:** два режима — «Сегодня» и «Для тебя». «Сегодня» сохраняет короткую дневную сессию и приоритет темы класса; назначенный материал отмечен «От учителя». Справа четыре действия: серии, «Проверить себя», лайк и звук. Тест и пересказ открываются из общего блока. Конспект, отправка ссылки, жалобы и настройка интересов — в меню «⋯».
- **Просмотр:** MP4, свайп, перемотка, пробел для паузы, один тап для паузы и двойной для лайка. Выбранный лайк красный. Анимации учитывают спокойный режим и системное уменьшение движения. На компьютере можно скрыть боковую информацию.
- **Библиотека:** поиск по названию и описанию, предметы, раскрывающиеся фильтры языка и класса. На телефоне — широкие карточки с обложкой слева; на компьютере — сетка.
- **Тема и тесты:** маршрут «серии → тест → пересказ», продолжение непросмотренной серии, серверная оценка, объяснения и переход к связанной серии после ошибки. Микровопросы и итоговые вопросы разделены; история попыток и ответов сохраняется. Практика по ошибкам не меняет итоговый балл. Просмотр и понимание учитываются отдельно.
- **Пересказ:** запись до двух минут, прослушивание, текстовое дополнение, согласие на сохранение, отзыв и оценка учителя, удаление своей записи. Пересказ добровольный, если его не назначил учитель.
- **Профиль:** карточка пользователя, переход к прогрессу, плитки интересов, выбор темы. Напоминание и личные данные раскрываются отдельно. Напоминания работают при открытом приложении; тихий период 21:00–08:00 (UTC+5).
- **Учитель:** классы, приглашения по коду, текущая тема, задания и сроки. Отчёт показывает ответы учеников, последние/предыдущие/лучшие результаты, частые ошибки и очередь пересказов. CSV учитывает фильтры.
- **Студия:** PDF с текстом / TXT / MD, сценарии и вопросы, загрузка MP4 или сборка в стилях «Карточка», «Доска», «Субтитры». Есть запись своего голоса, предпросмотр и публикация. Синтез речи и Ollama требуют отдельной настройки.
- **Авторы и модерация:** роль автора, правила проверки текста, очередь модератора, жалобы, история решений, статистика досмотров, лайков и первых ответов. ИИ только предлагает замечания. Справочник учебных тем примерный и требует проверки методистом.
- **Аккаунты и PWA:** роли, хеширование паролей, серверные сессии и разграничение доступа. Учительский материал по умолчанию доступен назначенным классам. Есть экран отсутствия сети; личные результаты и видео не кешируются для офлайн-просмотра.

## Локальный запуск

Нужны Node.js 22.12+, npm, Docker Desktop с Compose, FFmpeg и FFprobe в PATH. База — PostgreSQL; облачный сервис базы для локального запуска не требуется.

Текущая рабочая установка использует **порт 3000 из .env**:

- ученик: [127.0.0.1:3000](http://127.0.0.1:3000/);
- учитель: [localhost:3000/classes](http://localhost:3000/classes).

Это один сервер и одна база. Разные имена хоста позволяют держать отдельные сессии. Адрес 127.0.0.1 доступен на компьютере, где запущен сервер. Порт по умолчанию в коде и `.env.example` — **3100**; существующий `.env` сохраняется.

Для новой установки в PowerShell, из корня проекта:

```powershell
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
docker compose up -d db
npm run db:migrate
# Только для новой демонстрационной базы с DEMO_MODE=true:
npm run db:seed
npm run build
npm start
```

Для существующей установки после получения изменений достаточно применить новые миграции, собрать интерфейс и запустить сервер. Демонстрационный сид для обновления интерфейса не нужен. Для разработки — `npm run dev`.

Есть помощники `INSTALL-WINDOWS.cmd`, `START-WINDOWS.cmd` и `node scripts/local-start.mjs`. Автоматическую установку компонентов Windows целиком на чистом ПК пока не проверяли. В запускателе остаётся известная ошибка поиска свободного порта при занятом 3100; ручной запуск использует PORT из `.env`.

Получение проекта: `git clone https://github.com/Izumx/OylaTap.git` или [архив main](https://github.com/Izumx/OylaTap/archive/refs/heads/main.zip).

## Данные и перенос

Настройки подключения находятся в `.env`. Docker хранит PostgreSQL в томе postgres_data; удаление тома удаляет базу. Пользователи, задания, ответы и прогресс находятся в PostgreSQL. Обычные загрузки видео и аудио — в DATA_DIR (по умолчанию `.local/uploads`), пути и права доступа — в базе. Для переноса нужны **база и медиа**, а также файл Flow из репозитория.

`.env`, `.local/`, файлы аккаунтов и резервные копии не добавляются в Git. Данные входа текущей установки хранятся в `.local/МОИ-АККАУНТЫ.txt`.

Новый демонстрационный сид добавляет учебные примеры и демо-автора, а демо-учителю назначает модерацию. На существующей базе одни миграции не создают этих пользователей и не назначают модератора. Демонстрационные материалы показывают формат и не считаются проверенной школьной библиотекой.
