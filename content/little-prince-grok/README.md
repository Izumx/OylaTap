# «Кішкентай ханзада» — қазақша қысқаша мазмұн

Готовый ролик OylaTap: 38 секунд, 1080×1920, 24 кадра/с, H.264/AAC. Шесть сцен Grok со своими голосами, казахские подписи, монтаж и итоговый вопрос. MP4 и отдельные субтитры включены в репозиторий.

В каталоге — **мировая литература**, язык **қазақша**. 7-й класс обозначает рекомендуемый уровень просмотра, а не подтверждённое включение произведения в календарный план. Ролик дополняет чтение полной книги Антуана де Сент-Экзюпери. Учебные вопросы в `lesson.json` проверяют понимание, а финал оставляет возвращение героя неоднозначным.

Адрес: `/learn/a260b7a9-8f7c-4e8c-bd87-38f8d1ee0d20`.

Разрешение увеличено из исходников 400×736 и 720×1264; отсутствующие детали не восстанавливались. Подписи третьей сцены передают смысл по исходному сценарию: автоматическое распознавание части слов Grok неуверенное. Произношение стоит отдельно проверить перед школьной публикацией. Это художественная ИИ-интерпретация и авторский пересказ, а не дословные цитаты из перевода.

Полный монтаж создавался локально. В финальной сцене переходы с раздвоением персонажей заменены чистыми планами; голоса не заменялись. Файл `subtitles-kk.srt` содержит отдельные подписи, `cover.jpg` — кадр для обложки.

На новой демонстрационной базе `npm run db:seed` добавляет только этот ролик и готовый фильм про Керея и Жанибека. Для обновления существующей базы после резервного копирования: `npm run db:migrate`, затем `npm run content:sync`. Повторный запуск сохраняет ID существующих серий и вопросов, аккаунты и прогресс по оставленным темам.
