# Полный ролик: Керей и Жанибек

`npm run db:seed` добавляет тему с готовым MP4 и вопросами из `lesson.json` в демобазу. Повторный запуск не создаёт дубликатов. Для просмотра откройте `/watch/f9285ed2-b8cf-419e-83e8-c6844a65f74a`.

Сборка из шести уже созданных визуальных сцен Google Flow и шести отдельных фрагментов русской озвучки. Новая генерация и запросы к Google не выполняются.

Готовый ролик [`oylatap-khanate-full-ru.mp4`](oylatap-khanate-full-ru.mp4) включён в репозиторий. Тема «Керей и Жанибек: рождение Казахского ханства» использует этот файл и открыта в общей библиотеке по адресу `/learn/f9285ed2-b8cf-419e-83e8-c6844a65f74a`. В локальной PostgreSQL путь к ролику хранится относительно корня проекта, поэтому после переноса папки видео остаётся доступным.

`lesson.json` хранит порядок сцен, имена скачанных файлов, текст озвучки, субтитры и учебные вопросы. Исторические ориентиры сверены с [материалом портала «История Казахстана»](https://e-history.kz/ru/projects/show/23181). Видеосцены — художественная ИИ-реконструкция. Краткие субтитры местами сокращают озвучку для удобства чтения.

## Сборка

Нужны уже скачанные исходные MP4 и установленный FFmpeg с `libass`, `libx264` и `ffprobe`. Скрипт не скачивает инструменты.

```powershell
node scripts/prepare-flow-video.mjs "C:\path\to\downloads" ".local/flow-khanate-output"
```

При необходимости укажите полные пути к инструментам через `FFMPEG_PATH` и `FFPROBE_PATH`. Выходная папка должна быть новой: существующие файлы не перезаписываются.

Результаты: `oylatap-khanate-full-ru.mp4` (около 48 секунд, 720×1280, H.264/AAC), `cover.jpg`, отдельные субтитры `khanate-ru.srt`, текст озвучки и технический манифест `build.json`. Озвучка берётся из отдельных речевых клипов; исходные звуковые дорожки визуальных сцен заменяются. Громкость нормализуется по всему ролику в два прохода. Субтитры встроены в изображение, оставлено место под нижние элементы плеера.

Локальная проверенная сборка находится в `.local/flow-khanate-ready/`. Исходники и промежуточные части остаются локальными медиафайлами; готовый MP4, метаданные темы и воспроизводимый рецепт сохраняются в репозитории. Загрузка других MP4 в студию OylaTap проходит обычную проверку H.264 и длительности.
