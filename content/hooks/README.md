# Загадки к уроку

Шесть коротких серий (27–33 с) для режима «Угадай до урока». Каждая папка:

- `hook.json` — название, предмет, класс, тема программы, текст озвучки, вопрос с тремя вариантами, правильный ответ и раскрытие;
- `<slug>.mp4` — вертикальное видео 1080×1920, собранное в HyperFrames с синтезированной озвучкой.

`npm run content:sync` и `npm run db:seed` загружают их как опубликованные публичные сезоны `kind='hook'`
с постоянными id `30000000-0000-4000-8000-00000000000N`. Повторная загрузка не создаёт дублей.

Темы привязаны к стартовым темам программы и не заменяют календарный план школы: перед уроком учитель
проверяет вопрос и раскрытие.
