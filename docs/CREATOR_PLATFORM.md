# Авторы, модерация и лента «Для тебя»

Решение владельца от 15.10.2026: любой человек, который разбирается в теме, может стать автором. Он пишет объяснение, OylaTap собирает вертикальное видео без монтажа, модератор проверяет ролик, а лента показывает его ученикам, которые проходят эту тему сейчас.

## Роли

| Роль                             | Что может                                                                                                                     |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Ученик                           | Смотрит ленту, отвечает на вопросы, ставит лайки, жалуется на ошибки                                                          |
| Учитель                          | Всё, что умеет автор, плюс классы, задания и отчёты. Сезон «только для класса» публикуется сразу, под ответственность учителя |
| Автор (`creator`)                | Студия, свой голос, статистика. Публикует только в общую ленту                                                                |
| Модератор (`users.is_moderator`) | Очередь проверки, одобрение, возврат на доработку, решения по жалобам. Свой контент не модерирует                             |

В демо: `creator@demo.oylatap.local` — автор, демо-учитель одновременно модератор.

## Путь ролика

1. **Текст → серии.** Автор вставляет текст или PDF/TXT/MD. «Подготовить серии» режет текст без изменений, ИИ-черновик (Ollama) переписывает его в серии с вопросами. В промпт добавляются приёмы самых понятных роликов платформы, см. «Аналитика».
2. **Привязка к программе.** Предмет, класс и тема из `curriculum_topics`.
3. **Сборка видео** ([server/render.ts](../server/render.ts)):
   - «Доска»: шаги появляются по очереди, формулы выделены моноширинным шрифтом, старые шаги «стираются» сверху;
   - «Субтитры»: одна крупная фраза на экране, прогресс как в историях;
   - «Карточка»: весь текст на одном экране (прежний формат).

   Шаг — строка или предложение. Формулы пишутся отдельной строкой с `=` или в обратных кавычках. Голос: без озвучки, свой (запись в браузере или аудиофайл, смена шагов подстраивается под речь) или синтез (`TTS_COMMAND_RU/KK`, например Piper). На каждом кадре подпись `@автор · oylatap`: опубликованный ролик можно скачать для TikTok/Reels, и он сам приводит зрителей. Загруженный MP4 (Flow) пересборка не трогает.

4. **Автоматическая проверка** ([server/moderation.ts](../server/moderation.ts)) при отправке:
   - блокируются нецензурная лексика и реклама азартных игр;
   - модератору помечаются ссылки, телефоны, email, похожие на ИИН числа, призывы подписаться, чувствительные темы и возможная грубая лексика на казахском.
5. **Модерация.** Пока у автора нет доверия, ролик для общей ленты получает статус `moderation`. Если подключена Ollama, ИИ в фоне добавляет подсказки: возможные фактические ошибки, небезопасная подача, реклама. **ИИ ничего не публикует и не отклоняет сам.** Модератор видит серии, видео, правильные ответы, замечания и историю решений. Он одобряет или возвращает ролик с обязательным комментарием.
6. **Доверие.** После 3 одобренных сезонов без подтверждённых жалоб автор становится `trusted`. Его ролики без замечаний правил выходят сразу. Подтверждённая жалоба (снятие с публикации) возвращает автора к проверке.
7. **Жалобы.** «Нашёл ошибку?» под роликом: ошибка, небезопасно, реклама, чужой материал. Один ученик — одна жалоба на сезон. После 3 открытых жалоб ролик уходит из общей ленты, но остаётся у классов, которым его назначили. Дальше модератор либо отклоняет жалобы, либо снимает ролик.

## Лента «Для тебя»

`GET /api/foryou` выдаёт конечную подборку: до 6 сезонов и 8 роликов, не больше двух сезонов одного автора. Причина выбора показывается на ролике. Баллы ([server/recommend.ts](../server/recommend.ts)):

| Сигнал                                                      | Баллы     |
| ----------------------------------------------------------- | --------- |
| Тема класса, заданная учителем                              | +6        |
| Тема программы своего класса на текущей учебной неделе (±1) | +4        |
| Слабый последний тест (< 70%)                               | +2,5      |
| Интерес ученика                                             | +1,5      |
| Свой язык / чужой                                           | +1 / −1,5 |
| Свой класс / дальше чем на класс                            | +1 / −2,5 |
| Начатая тема                                                | +1        |
| Качество ролика (0–1)                                       | ×2        |
| Всё просмотрено и понято                                    | −6        |

Учебная неделя считается от 1 сентября (UTC+5); летом привязка к неделе не действует. Справочник тем ([db/009_curriculum_topics.sql](../db/009_curriculum_topics.sql)) — **примерный порядок тем, а не официальное КТП**. До пилота его должен проверить методист. Тема, заданная учителем классу, всегда важнее.

## Аналитика и «похожие на популярные»

Для каждого эпизода сохраняются максимальная досмотренная доля (`episode_views`), лайки и первые ответы на микровопрос. Качество ролика сглажено к нейтральному значению (10 «виртуальных» просмотров), чтобы ролик с тремя просмотрами не оказался в топе:

`качество = 0,4·досмотр + 0,2·лайки + 0,4·понимание`

Понимание весит столько же, сколько досмотр, а лайки меньше всего: так рейтинг не поощряет кликбейт. По стилям и по лучшей четверти роликов (от 20 просмотров) считаются подсказки: средняя длина серии, начало с вопроса, формулы отдельной строкой, лучший стиль. Их видит автор в студии, и они же уходят в промпт ИИ-черновика.

## Что не сделано намеренно

- **Реклама, платное продвижение, выплаты авторам.** Нужна юридическая проверка (данные несовершеннолетних, реклама детям) и реальная аудитория. Для будущего фонда авторов уже есть данные: доверие, просмотры, понимание.
- **Автоматическая проверка фактов.** ИИ только подсказывает; решение за человеком.
- **Синтез речи** подключается на сервере (Piper или аналог); качество казахской озвучки нужно проверить отдельно.
- **Проверка гипотезы на школьниках:** [VALIDATION_PILOT.md](VALIDATION_PILOT.md).
